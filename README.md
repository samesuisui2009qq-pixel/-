# 鸟类术语翻译助手（免费方案）

用浏览器自带的整页翻译，把网页里的鸟类英文名翻成《懂鸟/郑四版》规范中文名；
学名与 ad./juv./1st-w. 等缩写受保护，不会被机翻改写。全程免费、可离线、无 API。

## 文件

| 文件 | 用途 |
|---|---|
| `bird-translate.user.js` | 油猴脚本（核心） |
| `glossary.json` | 词库，11 905 条「英文名 → 中文名」 |
| `test.html` | 本地测试页，装好后先开它验证 |
| `test-core.js` | 逻辑自测（Node，可忽略） |

## 安装（约 3 分钟）

1. **装油猴**：Chrome/Edge 应用商店搜 `Tampermonkey` 安装（免费）。
2. **装脚本**：打开 Tampermonkey 面板 → 「添加新脚本」，或直接把 `bird-translate.user.js`
   拖进浏览器窗口 → 点「安装」。
3. **导入词库**：打开任意网页 → 点 Tampermonkey 图标 → 「① 导入词库 JSON」→ 选 `glossary.json`。
   导入成功右下角会提示「词库已载入：11905 条」。
4. **开启浏览器翻译**：右键页面 →「翻译成中文」；或在设置里把「始终翻译英语」打开。
5. **验证**：双击打开 `test.html`，右键翻译，鸟名应变中文、学名与缩写保持原样。

## 原理

```
页面文本 →（脚本）鸟名替换成占位符 Zq1Qz →（浏览器翻译）只翻普通文字
        →（脚本）把占位符还原成规范中文名
```

占位符是纯字母数字，机翻不会改动它，所以鸟名 100% 不跑偏。

## 菜单功能

| 菜单 | 作用 |
|---|---|
| ① 导入词库 JSON | 从本地文件载入/更新词库 |
| ② 设置词库 URL | 从网址自动下载词库（可放内网或网盘直链） |
| ③ 启用/停用 | 临时关闭术语替换 |
| ④ 重新扫描本页 | 单页应用切换内容后手动重扫 |
| ⑤ 查看状态 | 显示词条数与已生成占位数量 |

## 维护词库

`glossary.json` 就是一张表：`{"brown shrike": "红尾伯劳", ...}`（键必须小写）。
改完重新「① 导入词库」即可，无需改脚本。

生成新词库：`python build_glossary.py`（把 Excel 名录转成同名 json）。

## 常见问题

- **鸟名没变中文**：先确认菜单 ⑤ 显示词条数 > 0；再确认翻译是在脚本加载后触发的。
- **整段没被翻译**：占位符过多会让机翻「看不懂」而跳过；可在菜单 ③ 临时停用后整段翻译，
  或只对名录页启用。
- **译文里出现 `Zq1Qz`**：说明脚本被禁用或页面在 iframe 内；本脚本默认不跑 iframe。
- **想要更强的翻译质量**：把浏览器翻译换成任意「可上传术语表」的翻译插件，
  直接用 `glossary.csv` 作术语库，效果等价。
